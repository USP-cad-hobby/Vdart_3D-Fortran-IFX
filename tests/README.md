Tests and comparison runner

This directory contains simple helpers and saved comparison results used for baseline vs offset verification.

Reproduce the baseline / offset comparison

1) Build the project (Release|x64) in Visual Studio (recommended) so the executable is produced under x64\Release\.

2) Prepare the two executables in the repository `build\` folder:
   - Copy the baseline exe into build\vdart_baseline.exe
   - Copy the offset exe into build\vdart_offset.exe

   Example PowerShell (run from repo root):

   mkdir -Force build
   Copy-Item "x64\Release\Vdart3D_Fortran_mod.exe" ".\build\vdart_baseline.exe" -Force
   Copy-Item "x64\Release\Vdart3D_Fortran_mod.exe" ".\build\vdart_offset.exe" -Force

3) Run the executables in isolated folders under tests/ and generate torque CSVs and run outputs. Example (PowerShell):

   mkdir -Force .\tests\baseline_run; Push-Location .\tests\baseline_run; & '..\\build\\vdart_baseline.exe' *> output_run.txt 2>&1; Pop-Location
   mkdir -Force .\tests\offset_run; Push-Location .\tests\offset_run; & '..\\build\\vdart_offset.exe' *> output_run.txt 2>&1; Pop-Location

4) Run the comparator and side-by-side report generators:
   - tools/compare_baseline.py generates a compare_summary.txt for a single run (expects torque_vs_azimuth.dat and output_run.txt in the working folder).
   - tests/compare_side_by_side.py creates tests/results/combined_comparison.txt and tests/results/combined_torque_delta.csv from tests/baseline_run and tests/offset_run.

   Example:
   python tools/compare_baseline.py      # run inside tests/baseline_run or tests/offset_run
   python tests/compare_side_by_side.py # create combined summary and CSV

Files produced and meaning

- tests/baseline_run/ and tests/offset_run/
  - torque_vs_azimuth.dat  : raw per-azimuth torque diagnostic generated by the executable
  - torque_vs_azimuth.csv  : CSV version of the torque file (azimuth_deg, torque_Nm)
  - output_run.txt          : entire console output captured during the run
  - compare_summary.txt    : human-readable comparison against the legacy baseline (created by tools/compare_baseline.py)

- tests/results/combined_comparison.txt
  - Combined summary showing baseline and offset mean torque and CP, plus deltas.

- tests/results/combined_torque_delta.csv
  - Per-azimuth table with columns: azimuth_deg, torque_baseline_Nm, torque_offset_Nm, delta_Nm, delta_pct

Notes

- Prefer building inside Visual Studio (devenv) because msbuild may not invoke the Intel Fortran toolchain for .vfproj projects.
- Do not commit large binary outputs. The repository already ignores common build artifacts via .gitignore.
